# Contributing to Q-Sentra

First off, thank you for considering contributing to Q-Sentra! 

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct. We expect all contributors to maintain a welcoming and inclusive environment.

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please create an issue detailing:
- The context and environment.
- Steps to reproduce the behavior.
- Expected vs. actual behavior.

### Suggesting Enhancements

We welcome feature requests and enhancements. Please open an issue to discuss your ideas before submitting a Pull Request, especially for significant architectural changes.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`pytest`).
4. Format your code using `black` and ensure it passes `flake8` linting.
5. Issue that pull request!

## Local Development Setup

Refer to the `README.md` Quickstart section for instructions on setting up the FastAPI backend and React frontend locally using Docker Compose or native environments.

## Formatting and Linting

- Python Backend: We use `black` for formatting and `flake8` for linting.
- React Frontend: We use `eslint` and `prettier`.

Ensure all checks pass before requesting a review.
